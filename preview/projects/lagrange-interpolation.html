Lagrange Polynomial Interpolation

A small browser-based tool for calculating a polynomial from user-entered points using Lagrange interpolation, then visualizing the resulting curve.

JavaScriptHTML / CSSChart.jsBootstrap

How it works

Enter X/Y points
Calculate the polynomial
View formula and chart

The idea

Polynomial interpolation constructs a function passing through a set of distinct data points. I made this web tool to explore the Lagrange method through a practical, interactive interface rather than a static calculation.

Implementation

The UI lets a user add or remove rows of X/Y values. Plain JavaScript calculates the interpolation coefficients and formats the polynomial, while Chart.js plots the calculated curve and the supplied points. The form also flags duplicate X values, for which Lagrange interpolation is undefined.

What you can inspect

The public repository includes the interpolation logic, the input-handling code, the chart-rendering code and a README explaining how to run the project locally. It is a compact standalone JavaScript project, not part of my professional business systems work.
