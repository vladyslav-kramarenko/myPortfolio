Numerical Methods

An interactive browser-based laboratory for studying numerical algorithms, inspecting intermediate calculations and comparing numerical accuracy.

JavaScriptHTML / CSSMathMLSVG / CanvasNode.js testsCloudflare Workers

How it works

Choose a method and load data
Check applicability and solve
Inspect steps, errors and plots

From desktop to web

The project builds on the original 2017 Java numerical methods application. The web implementation runs entirely in the browser and uses independent JavaScript implementations of the algorithms, rather than a direct line-by-line translation.

Numerical methods and diagnostics

The laboratory covers 12 methods for linear systems, matrix operations, nonlinear equations, eigenvalues, interpolation, quadrature and boundary-value problems. It includes relative residuals, condition estimates, convergence histories and applicability checks. Numerical error indicators are not presented as universal guarantees.

Educational interface

Thirty-nine loadable examples, including academic exercises and intentional convergence failures, share data with regression tests. The site provides five languages, 65 localized static pages, native MathML formulas, interactive plots and JSON, HTML and print-ready reports.

Architecture

A shared numerical engine and static site generator keep the implementation independent of external runtime libraries. The public repository separates development and production branches, retains the original Java source, and includes numerical and site regression tests. Deployment uses Cloudflare Workers static assets.
